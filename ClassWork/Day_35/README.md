## Day 35 : 
## Recurrent Neural Networks (RNN) and Transformers – Concept Demonstrations : 
---

It contains Python programs focused on understanding the internal working of **Recurrent Neural Networks (RNNs)** and **Transformer architectures** using simple, step-by-step implementations.

The programs are written with detailed explanations, mathematical intuition, and beginner-friendly demonstrations to help understand how modern NLP models process text data.

---

# Topics Covered

## Recurrent Neural Networks (RNN)

The RNN section demonstrates how sequential neural networks process text one word at a time and maintain memory using hidden states.

Concepts covered include:

* Embedding Layers
* Time Steps in RNN
* Hidden State Memory
* Manual Hidden State Calculations
* Tanh Activation Function
* Sigmoid Activation Function
* Binary Crossentropy Loss
* RNN Architecture Building
* Model Compilation and Training
* Prediction Flow
* Complete Sentiment Analysis Workflow
* Mathematical Visualization of RNN Internals

---

# Transformer Architecture

The Transformer section explains modern attention-based architectures used in NLP models such as BERT, GPT, and machine translation systems.

Concepts covered include:

* Self Attention
* Query, Key, Value Calculation
* Attention Score Computation
* Scaled Dot Product Attention
* Softmax Attention Weights
* Multi-Head Attention
* Positional Encoding
* Transformer Encoder
* Transformer Decoder
* Encoder-Decoder Attention
* Masked Self Attention
* Decoder-Only Transformer (GPT Style)
* Neural Machine Translation
* Sentiment Classification using Transformers

---

# Learning Approach

The programs are intentionally designed with:

* Step-by-step explanations
* Printed intermediate outputs
* Manual mathematical calculations
* Visual demonstrations
* Beginner-friendly coding style
* Educational comments for every stage

The focus is on understanding *how* the models work internally rather than simply using prebuilt APIs.

## Day 34 : 
## Implementations of Deep Learning concepts using Python and popular libraries such as TensorFlow, Keras, Scikit-learn, NumPy, and Pandas : 
---

### 📚 Concepts Covered

---

- **Dataset Preparation** → Organizing and preparing raw data before training a model.  

- **Tokenization** → Converting words or text into numerical tokens for processing.  

- **Vocabulary Creation** → Creating a dictionary of unique words from the dataset.  

- **Text to Sequence Conversion** → Transforming sentences into numerical sequences.  

- **Sequence Padding** → Making all input sequences equal in length by adding padding values.  

- **Embedding Layer** → Converting words into dense vector representations that capture meaning.  

- **Time Steps** → Processing sequential data one element at a time in sequence models.  

- **Hidden States** → Maintaining previous information in RNNs to learn context.  

- **Tanh Function** → Activation function that maps values between -1 and 1.  

- **Sigmoid Function** → Activation function used for binary predictions with output between 0 and 1.  

- **Binary Crossentropy Loss** → Loss function used for binary classification tasks.  

- **LSTM Architecture** → Advanced RNN architecture capable of learning long-term dependencies.  

- **Time Series Forecasting** → Predicting future trends using historical sequential data.  

- **Breast Cancer Classification** → Predicting cancer type using medical dataset features.  

- **Model Compilation** → Configuring optimizer, loss function, and metrics for training.  

- **Model Training** → Teaching the neural network using training data.  

- **Model Evaluation** → Measuring model performance using evaluation metrics.  

- **Confusion Matrix** → Comparing predicted and actual classifications.  

- **Classification Report** → Displaying precision, recall, F1-score, and accuracy metrics.

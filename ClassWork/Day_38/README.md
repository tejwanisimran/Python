## Day 39 : 
## Data Analytics Using Python, Pandas, and Matplotlib : 
---

- It contains a Python-based Data Analytics application developed using **Pandas** and **Matplotlib**. It demonstrates how to load, analyze, and visualize student data using real-world analytics techniques.

- The application performs SQL-like analysis on CSV datasets and generates meaningful insights through graphical visualizations.

---

# Application Overview

The system reads student data from a CSV file and performs:

* Data Loading
* Data Inspection
* Data Cleaning Checks
* Statistical Analysis
* SQL-like Aggregations
* Business Intelligence Reporting
* Data Visualization

---

# Features

## Dataset Analysis

The application provides:

* Complete Dataset Display
* First Five Records Preview
* Dataset Shape Analysis
* Column Information
* Data Type Inspection
* Missing Value Detection

---

### SQL-Like Analytics
---

- The project performs analytical operations such as:

### Student Analysis

* Course-wise Student Count
* City-wise Student Count
* Gender Distribution

### Academic Analysis

* Average Marks by Course
* Highest Marks
* Lowest Marks
* Top Performing Students

### Attendance Analysis

* Average Attendance by Batch
* Low Attendance Student Detection

### Financial Analysis

* Course-wise Fees Collection
* Total Revenue Analysis

### Course Performance Report

* Total Students
* Average Marks
* Average Attendance
* Total Fees Collection
* Highest Marks
* Lowest Marks

---

### Data Visualization
---

- The application generates multiple charts for better understanding of data.

### Visual Reports

* Course-wise Student Count (Bar Chart)
* Average Marks by Course (Bar Chart)
* Gender Distribution (Pie Chart)
* City-wise Student Count (Bar Chart)
* Attendance Analysis (Bar Chart)
* Fees Collection Analysis (Bar Chart)
* Marks Distribution (Histogram)

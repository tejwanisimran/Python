## Day 33 : 
## Deep Learning using TensorFlow and Keras
---
- This  provides a practical introduction to Deep Learning using TensorFlow and Keras through beginner-friendly implementations of Recurrent Neural Networks (RNNs) and Convolutional Neural Networks (CNNs). It demonstrates important concepts such as tokenization, embeddings, sequence processing, sentiment analysis, character prediction, sequence prediction, image classification, and industrial surface crack detection. The programs are designed to simplify complex neural network concepts using small, understandable examples for learning and educational purposes.
